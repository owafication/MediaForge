# MediaForge desktop app overview

**Status:** Proposed product overview grounded in the inspected 1.1.0 source and supplied assessment.

## Product statement

MediaForge is a local Windows application for converting, preparing, inspecting and lightly assembling image, video and audio files. It is designed for users who want reliable batch workflows and professional control without uploading media or learning a full non-linear editor.

## Primary users

- General Windows users converting phone, camera, downloaded or archived media
- Creators preparing media for web, social, messaging, editing and archive workflows
- Audio users normalising, extracting or repackaging tracks
- Technical users who need explicit stream, codec, metadata and verification evidence
- Small teams/operators running repeatable local watch-folder workflows

## Primary outcomes

1. Build a mixed queue, apply reusable settings and run it without damaging sources.
2. Save longer work as a recoverable project and resume after restart or file movement.
3. Understand what the selected FFmpeg build and local hardware can actually do.
4. Preview the intended processing path closely enough to make dependable crop/trim/quality decisions.
5. Inspect and control streams, metadata, chapters and subtitles where supported.
6. Receive verified outputs, transparent warnings and useful support evidence.

## Core workflows

### Quick conversion
Add files → select preset → review compatibility/path summary → start → verify → open output/report.

### Project workflow
Create/open project → import/relink → edit clips → apply presets/per-job overrides → autosave/recover → run selected jobs → save history/report.

### Quality workflow
Select job → choose target quality/size → test an interval → compare → approve settings → full conversion → verification.

### Professional stream workflow
Inspect streams → choose copy/encode/remove/add/burn policies → review per-stream plan → run → verify mapping/metadata.

### Automation workflow
Authorise watch folder → dry run → stable-file detection → queue with preset → verify → move/report/notify according to rule.

## A-class definition

MediaForge becomes A-class when it is trustworthy for long jobs and unattended batches: durable projects, deterministic presets and overrides, truthful compatibility, preview/export alignment, explicit processing paths, conservative lossless decisions, verification tiers, privacy-safe diagnostics, accessible Windows UI and reproducible releases.

## Boundaries

Included: conversion, batch processing, crop/resize, single-track clip assembly, stream/metadata preparation, local automation and reports.  
Excluded: unlimited multi-track editing, complex compositing, cloud media hosting, collaboration, marketplace, DRM circumvention and generative AI.
